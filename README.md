# Proyecto: Ingeniería de Software (AS-IS)

Repositorio de trabajo para el análisis y modelado del proceso de salida de campus (compra/validación de boleto), enfocado en diagrama de actividades AS-IS.

## Objetivo de la actividad
- Pasar del discurso narrativo al modelo formal.
- Detectar inconsistencias y lagunas de información.
- Enfocarse en precisión conceptual (no perfección gráfica).

## Entregables esperados
1. Diagrama de actividades AS-IS.
2. Lista de actores.
3. Lista de pain points con evidencia asociada.
4. Explicación breve (máx. 1 página).

## Estado actual
- Flujo principal y rutas alternas ya modeladas en borradores.
- Se identificó que aún faltan: normalizar swimlanes por actor, cerrar ramas/merges y reforzar pain points con evidencia explícita.

## Estructura
- `contexto/actividad.md`: instrucciones de la actividad y criterios.
- `contexto/actores-flujo-painpoints.md`: propuesta textual para entrega.
- `assets/`: archivos fuente (PDF/DOCX) y capturas.
- `links.md`: vínculos a Lucid/draw.io/SharePoint.

## Nota
Este repo guarda contexto de trabajo para facilitar continuidad con el asistente y el equipo.
